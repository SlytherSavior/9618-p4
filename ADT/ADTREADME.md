# 📚 Abstract Data Types (ADT) Implementation Guide
## Cambridge International AS & A Level Computer Science (9618) - Paper 4

This repository provides comprehensive implementations and explanations of Abstract Data Types (ADTs) required for Cambridge International A Level Computer Science Paper 4. The implementations are available in both Python and Java, making it accessible for students regardless of their preferred programming language.

## 📋 Contents

### 1. Abstract Data Types Covered
- **Stack**
  - Array-based implementation
  - Push, Pop, and Peek operations
  
- **Queue**
  - Linear Queue implementation
  - Circular Queue implementation
  - Enqueue and Dequeue operations
  - Front/Rear pointer management
  
- **Linked List**
  - Single Linked List
  - Node structure and pointer manipulation
  - Insertion ( Ordered Insertion )
  - Deletion operations

- **Binary Trees**
  - Tree traversal methods
  - Node structure and two pointers manipulation
  - Insertion ( Ordered Insertion )
  - Deletion operations

### 2. Searching Algorithms
- Binary Search (Recursive implementation)
- Linear Search



## 🚀 Getting Started

### Prerequisites
- Python 3.x
- Java JDK 20.0.1 or higher
- Basic understanding of ADT concepts

### Setup Instructions
1. Clone the repository:
   ```bash
   git clone https://github.com/SlytherSavior/9618-p4.git
   cd 9618-p4
   ```

2. Choose your preferred language directory:
   - `/python` for Python implementations
   - `/java` for Java implementations

## 📝 Paper 4 Examination Tips

### ADT Implementation Guidelines
1. **Always initialize** your data structures with appropriate size constraints
2. **Include boundary checking** for all operations
3. **Implement error handling** for overflow/underflow conditions
4. **Comment your code** to explain the logic
5. **Use meaningful variable names** that reflect their purpose

### Common Examination Questions
- Implementation of basic ADT operations
- Modification of existing ADTs
- Combining multiple ADTs
- Traversal and searching operations
- Error handling and edge cases
